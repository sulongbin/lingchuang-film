# 灵创智影影视全流程

**从剧本与资产，到经确认的生成任务，再到 Windows 剪映可编辑交付。**

`lingchuang-film` 是面向 Codex 的 AI 影视制作技能包。客户只使用一个入口，选择短剧或商业路线；已有剧本、图片和视频可以直接接续，只补缺项。它调用灵创智影会员 API 进行生产，并用本地工具组织素材、制作预览和交付剪映草稿。

当前交付版本：**v0.1.2**。这是文档与打包补丁，生产脚本与 v0.1.1 保持一致。它不是独立软件，也不附带模型额度。

## 可以完成什么

| 环节 | 随包提供的能力 |
|---|---|
| 短剧编剧 | 选题、人物、结构、正式剧本与分镜脚本；封装实际 `5min-drama-contest` 资源 |
| 影视总导演 | 商业创作、资产、分镜、运镜、表演、连续性检查、审片与定点返修；封装实际 `ai-film-general-skill` 资源 |
| 平台生产 | 通过 `lingchuang-video` 管理会员鉴权、兼容模型选择、报价、提交、查询、结算记录、同画布和下载 |
| 动作参考 | 可选深度白膜转换；原片确认、单独报价、验收后按目标模型能力引用 |
| 版本管理 | 保留任务和来源，记录验收与采用版本；只交付最终确认素材 |
| 本地剪辑 | 字幕和声音短预览、初剪、分轨声音、MP4、Windows 剪映可编辑草稿 |

模块按需读取，不要求客户分别选择多个技能。完整规则见 [技能入口](https://github.com/sulongbin/lingchuang-film/releases/tag/v0.1.2)；学员可阅读 [使用与交付说明 PDF](灵创智影影视全流程学员使用与交付说明.pdf)。

## 制作流程

1. 选择短剧或商业路线，核对已有剧本和资产。
2. 确认图片方案与费用，生成后验收人物、场景、道具和分镜。
3. 确认视频方案与费用，提交后查询结果并逐镜验收。
4. 必要时单独确认返修、动作白膜或超分；保留来源与版本。
5. 先看声音与字幕短预览，确认后应用全片。
6. 选用最终确认素材，交付初剪 MP4、字幕和 Windows 剪映草稿。

对白优先使用视频模型原生声音，客户可在剪映中替换音色。付费配音、配乐和后处理分别报价；本地预览确认不会自动授权新的付费生成。

## 方案和费用

默认提供基础、标准、高级三档，也允许指定兼容模型。模型组合、参数、权限与费用以**运行时会员目录和有效报价**为准，不根据模型名称推断能力，不在文档中固定实时价格。

图片与视频阶段分别确认方案和费用，生成结果另行验收。报价过期或变化后须重新确认；网络超时、响应丢失等不确定提交保留原报价核对，不能自动换报价再次生成。实际积分和结算状态按任务追溯，未结算不按零积分处理。详见 [报价恢复说明](https://github.com/sulongbin/lingchuang-film/releases/tag/v0.1.2)。

## 安装与开始

准备 Windows、Codex、Python 3.11+、剪映专业版和自己的灵创智影会员 API Key。下载 [v0.1.2 Release](https://github.com/sulongbin/lingchuang-film/releases/tag/v0.1.2) 中的交付 ZIP，解压进入 `lingchuang-film` 目录后运行：

```powershell
.\install.ps1
```

安装器创建独立 Python 环境并安装依赖。目标目录已经存在时会停止，不覆盖旧技能。完整安装、手动安装与更新步骤见 [安装与启动说明](https://github.com/sulongbin/lingchuang-film/releases/tag/v0.1.2)。

安装并重新加载技能后，在自己的作品目录输入：

> 使用 $lingchuang-film。我选择商业路线，先读取已有脚本和资产，只补缺项。按标准方案列出下一阶段方案与费用，等我确认后再生成。同一作品复用同一画布，最终只把我确认采用的素材交付 Windows 剪映。

短剧用户将“商业路线”改为“短剧路线”即可。

## 验证与使用边界

- v0.1.2 发布前记录：47 项离线测试通过，未进行真实付费生成。
- Windows 剪映 11.5.0.14471：独立两镜头样例由用户确认可打开、编辑字幕与音轨、保存后重开。该记录不代表所有版本或媒体均兼容。
- 包含 8 秒合成样例的 MP4、字幕、音轨验证；样例不是艺术成片质量证明。
- 首版不包含 Shotcraft、自动语音识别、自动音色替换、口型修复或独立音效生成 API。复杂本地特效和转场库不在本版范围内。

详细证据与限制见 [能力与验证状态](https://github.com/sulongbin/lingchuang-film/releases/tag/v0.1.2)、[验证结果](https://github.com/sulongbin/lingchuang-film/releases/tag/v0.1.2) 和 [版本记录](CHANGELOG.md)。
